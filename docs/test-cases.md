## 人工验收建议

1. 分别登录三种账号，确认导航、创建按钮、分派控件和可见数据不同。
2. 新建工单后由管理员分派、技术人员处理、普通员工关闭，核对操作记录顺序。
3. 筛选“已超时”，由管理员升级并确认 L1 标识及日志。
4. 带筛选条件导出 CSV/Excel，核对行数和字段。
5. 缩窄浏览器窗口，检查登录、列表和详情的基本可用性。

## 已知边界

- 自动化测试以 API 和核心业务为主，尚未加入浏览器端 E2E 测试。
- SQLite 适合演示，未覆盖高并发和故障切换。
- 演示令牌机制未实现刷新令牌、找回密码和账户锁定。
