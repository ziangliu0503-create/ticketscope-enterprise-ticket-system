# 测试用例

## 自动化测试

| 编号 | 场景 | 预期结果 |
|---|---|---|
| AT-01 | 请求健康检查与基础配置 | 返回正常状态和可选项 |
| AT-02 | 查询第一页工单 | 返回正确总数及指定数量记录 |
| AT-03 | 按状态筛选 | 返回记录状态全部符合条件 |
| AT-04 | 创建并依次推进工单 | 完成分配、处理和解决 |
| AT-05 | 从待受理直接关闭 | 返回400并拒绝非法流转 |
| AT-06 | 获取看板 | 看板总数及状态分组与数据库一致 |

执行：

```bash
pytest -q
```

## 手工验收

### TC-01 创建普通工单

1. 点击“创建工单”。
2. 填写全部必填字段。
3. 提交表单。

预期：显示新工单，状态为待受理，自动生成工单编号。

### TC-02 必填项检查

1. 创建工单时不填写标题。
2. 提交表单。

预期：浏览器或服务端阻止提交并显示错误。

### TC-03 完整状态流转

1. 打开待受理工单。
2. 选择负责人并更新为已分配。
3. 更新为处理中。
4. 填写解决方案并更新为已解决。
5. 更新为已关闭。

预期：每一步状态正确，操作记录完整。

### TC-04 解决方案检查

1. 将处理中工单更新为已解决。
2. 不填写解决方案。

预期：系统拒绝操作并提示必须填写解决方案。

### TC-05 列表筛选

分别选择状态、优先级、部门和问题类型。

预期：表格中的记录均满足当前筛选条件，重置按钮恢复全部记录。

### TC-06 看板核对

对比看板工单总数和列表总数。

预期：二者一致；状态分布合计等于工单总数。
