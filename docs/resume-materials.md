# 简历项目表述

## 推荐项目名称

**TicketScope 企业 IT 工单与 SLA 运营系统｜个人项目**

技术栈：Python、Flask、SQLite、Vue 3、ECharts、REST API、Pytest、Docker

## 通用版本（三条）

- 面向企业 IT 服务台场景完成需求拆解与流程设计，建立普通员工、技术人员、管理员三角色权限矩阵，以及工单分派、处理、解决、关闭和重开状态机。
- 使用 Flask、SQLite 与 Vue 3 实现工单全流程管理，增加 SLA 临期/超时识别、L1–L3 升级、操作日志、筛选查询和 CSV/Excel 报表导出。
- 使用 ECharts 搭建角色数据隔离的运营看板，并以 Pytest 覆盖登录、权限、非法流转、SLA 和导出等核心规则；完成 Gunicorn、Docker 与云部署配置。

## 数字化实施 / IT 支持版本

- 根据企业报障流程梳理角色、字段、状态、SLA 与验收标准，将口头报障转化为可分派、可追踪、可复盘的工单闭环。
- 实现三角色数据权限、负责人分派、解决方案和操作时间线，支持 SLA 风险筛选及超时升级，便于定位待办与服务风险。
- 编写部署手册、接口说明和测试用例，完成本地及生产模式验证，可独立进行系统演示和问题排查。

## 产品 / 需求分析版本

- 从用户痛点出发输出 PRD、角色权限矩阵、状态流程、数据模型和验收标准，并处理越权、非法跳转、重开等异常场景。
- 设计总量、解决率、平均处理时长、SLA 达标率等指标口径，完成看板、筛选和明细导出，支持运营复盘。
- 通过接口测试验证角色数据隔离和业务规则，沉淀产品文档、API 文档与迭代方案。

## 数据运营版本

- 构建工单运营指标体系，统一解决率、平均处理时长、SLA 达标率、临期和超时口径，按部门、类型、优先级与时间趋势进行可视化。
- 实现组合筛选和 CSV/Excel 导出，保证看板、列表和导出共用数据权限与筛选口径。
- 使用 220 条程序生成的模拟工单完成数据验证，编写自动化测试核对汇总与明细一致性。

## 技术岗位版本（仅投初级应用开发/实施开发）

- 使用 Flask 设计 REST API 与签名令牌认证，在查询层实施角色数据范围，在服务端实现状态机、SLA 计算和异常校验。
- 使用 Vue 3 和 ECharts 构建响应式工单页面与运营看板，通过 openpyxl 生成格式化 Excel 报表。
- 使用临时数据库完成 8 个 Pytest 接口测试，并配置 Gunicorn、Docker Compose 与 Render Blueprint。

## 使用建议

- 一页简历最多保留 3 条，每条突出“做了什么 + 怎么做 + 验证结果”。
- 投实施/IT 支持优先用对应版本；投产品/数据岗位替换为对应表述。
- 面试前必须能够现场演示，并能解释 RBAC、状态机、SLA、数据库关系和测试方法。
- “8 个测试通过”和“220 条模拟数据”可写，因为有项目证据；不要把模拟数据包装成真实业务数据。
